# Tecspaze

Erfasst deine Zeit im Tecspaze automatisch – mit Tagesziel, Rangliste, Community, Support-Chat und Mitteilungen.

## Installieren

- **Android:** [tecspaze.apk herunterladen](https://github.com/theD-Creator/tecspaze-app/releases/latest/download/tecspaze.apk) → öffnen → installieren
  (beim ersten Mal „Unbekannte Apps installieren“ erlauben). Neue Versionen zeigt dir die App selbst mit einem Download-Button.
- **iPhone & Computer:** [tecspaze.expo.app](https://tecspaze.expo.app) – auf dem iPhone über „Teilen → Zum Home-Bildschirm“.

## Entwicklung

Expo SDK 58 · React Native · Supabase

```bash
npm install
npx expo start
npm test
```
